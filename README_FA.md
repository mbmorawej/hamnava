# راهنمای انتشار «آهنگ‌های دوستان»

## ۱. ساخت پایگاه داده
1. به https://supabase.com بروید و حساب بسازید.
2. New project را بزنید و نام و رمز پایگاه داده را تعیین کنید.
3. از SQL Editor گزینه New query را بزنید، محتوای `schema.sql` را جای‌گذاری و Run کنید.
4. در Authentication > Providers > Email ورود ایمیلی را فعال نگه دارید. اگر تأیید ایمیل روشن باشد، هر کاربر باید ایمیل خود را تأیید کند.
5. از Project Settings > API Keys (یا Connect در داشبورد جدید) نشانی Project URL و کلید Publishable/anon را بردارید. هرگز کلید secret یا service_role را در HTML قرار ندهید.

## ۲. انتشار صفحه با GitHub Pages
1. در https://github.com یک مخزن عمومی جدید مثلاً `music-friends` بسازید.
2. فایل `index.html` را در ریشه مخزن آپلود و Commit کنید. (فایل SQL را نیازی نیست منتشر کنید.)
3. در Settings > Pages، بخش Build and deployment، Source را روی Deploy from a branch بگذارید؛ Branch را `main` و پوشه را `/ (root)` انتخاب و Save کنید.
4. پس از انتشار، آدرس معمولاً به شکل `https://USERNAME.github.io/music-friends/` خواهد بود.
5. آدرس صفحه را باز کنید، Project URL و Publishable/anon key را وارد کنید و «اتصال» را بزنید.
6. برای دوستان نیز همین دو مقدار عمومی را بفرستید؛ هرکس در اولین ورود باید آن‌ها را یک‌بار وارد کند. سپس ثبت‌نام و ورود کند.

## ۳. نکات مهم
- اطلاعات آهنگ‌ها بین اعضای ثبت‌نام‌شده مشترک است؛ هر عضو فقط آهنگ‌های خودش را حذف می‌کند.
- ثبت‌نام پیش‌فرض Supabase برای همه دارندگان آدرس سایت باز است؛ برای گروه خصوصی واقعی باید ثبت‌نام عمومی را غیرفعال و کاربران را از داشبورد دعوت کنید.
- کلید Publishable/anon عمومی است، اما کلید secret/service_role محرمانه است.
- این نسخه لینک آهنگ را ذخیره می‌کند و فایل موسیقی را روی سرور آپلود نمی‌کند.
- برای جلوگیری از نقض حق نشر، فقط لینک‌های مجاز و قابل اشتراک را اضافه کنید.
- این نسخه تا ۱۰۰۰ آهنگ جدید را نمایش می‌دهد؛ برای آرشیو بزرگ‌تر باید صفحه‌بندی اضافه شود.
- تغییرات با دکمه «به‌روزرسانی» دریافت می‌شوند، نه به‌صورت لحظه‌ای.
